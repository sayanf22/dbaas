# Research before deciding (all work)

- MUST: when unsure, confused, or relying on memory for a version, price, API, flag, limit, security practice or best practice, search the web BEFORE deciding or writing it down.
- MUST: prefer official documentation, release notes, changelogs and source code over blogs, forums and AI summaries.
- MUST: cross-check with a second source when sources disagree, or when the best source is more than a year old.
- MUST: record what was found (URL + check date) in the Sources section of the plan file that uses it, or in the PR note for code.
- MUST: provider prices are marked **verify** and re-checked at the build-plan step that spends money.
- MUST: never present an assumption as a fact. Say what was verified, what wasn't, and what is a planning value versus a measurement.
- MUST: then explain the finding step by step: what was asked, what the sources say, what was decided and why.
- MUST: if a finding contradicts the plan, stop and flag it (see `00-project-context.md`); don't silently diverge.
